Tool

Reconciliation checker

Compare two files that should agree and list every line that does not: amounts that differ, keys that appear twice, and records present in one file but not the other. Typical uses include an invoice against purchase orders, a payout report against orders, or a bank statement against a ledger export.

File B: your records

How it works

Each line in File A is matched to File B on the key you choose. A line agrees if the amounts are within the tolerance. Lines in File A with no match, lines in File B that were never billed, and keys repeated in File A are listed as exceptions. Both file totals are re-added from the line detail as a check on the result.

The checker identifies differences. Establishing the cause and supporting evidence for each, across a longer period, is covered in a paid engagement. See services and fees.
